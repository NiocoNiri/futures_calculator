# Проверка браузеров — 26 октября 2026

Проверена локальная копия deploy/app.py. Приложение и VPS не изменялись.
Сервер: стандартный WSGI для тестов, а не производственный Waitress/Caddy.
Данные: 500 синтетических контрактов; без реальной сети Мосбиржи.
Авторизация: тестовые HTTP Basic credentials только для localhost.

## Результаты

Chromium на Linux: пройдены загрузка с авторизацией, поиск по 500 контрактам,
расчёты только TP и только SL, ручная цена входа, сохранение порядка контрактов,
восстановление после сетевого сбоя. Проверены размеры 1366×768, 390×664
(профиль iPhone 13), дополнительно ширина 320 px. Горизонтального выхода
страницы за экран и необработанных ошибок JavaScript не обнаружено.
Профиль iPhone в Chromium не является тестом Safari или реального iPhone.

При запрете localStorage приложение загружается, порядок можно менять
в текущей вкладке. Перерисовка 493 результатов поиска занимает около 2.5–4 мс
на тестовой машине, 32.5 мс при шестикратном замедлении CPU. Это измерение JS,
не полная длительность от нажатия клавиши до вывода кадра на устройстве.

Искусственная задержка API вызвала штатный тайм-аут через 20003 мс;
после восстановления API обновление снова заработало.

WebKit не запустился: отсутствуют библиотеки Ubuntu, необходимые загруженной
сборке; используемая ОС не поддерживается Playwright официально.
Реальные Windows/iOS, конкретные VPN, TLS, DNS и производственный сервер не проверены.

## Подтвержденные недостатки

1. HTTP 401, HTML-ответ прокси (502), сетевая ошибка и тайм-аут отображаются
   одинаковым сообщением. По интерфейсу невозможно определить причину.
2. Обновление котировок пересоздаёт кнопки контрактов и сбрасывает клавиатурный
   фокус с кнопки на BODY. Это может мешать управлению клавиатурой.
   Горизонтальная прокрутка списка в мобильном Chromium при обновлении сохранилась.

Эти результаты не устанавливают причину ошибки на конкретном устройстве пользователя.

## Следующая проверка на проблемных устройствах

Нужны точный URL, браузер и его версия, версия ОС, описание симптома и VPN.
На Windows открыть F12 → Network, нажать «Обновить», проверить /api/market:
HTTP-статус, время ответа, тип содержимого; также проверить /api/calculate.
Не передавать заголовок Authorization, пароли или необработанный HAR.
Сравнить один и тот же браузер с VPN и без него, затем другой браузер той же ОС.
На iPhone проверить Safari, обычный/частный режим, возврат после блокировки экрана
и переключение Wi-Fi/мобильной сети. Для систематической проверки нужны реальный
iPhone и Windows либо соответствующий сервис тестирования.

## Повторный запуск

В этой папке:

```bash
npm install
npx playwright install chromium webkit
python server.py
```

В другом терминале из этой же папки:

```bash
npm test
```

На совместимой ОС могут потребоваться системные зависимости Playwright.
Сервер слушает только 127.0.0.1:8765; остановка — Ctrl+C.
Основной набор фиксирует недоступные браузеры в results.json, поэтому код завершения
сам по себе не означает, что все браузеры были проверены. Нужно читать status
для каждого профиля. Дополнительные проверки сохраняются в extra-results.json.
